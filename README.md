# Deck2Win

**The app Windows Virtual Desktops should have been.**

Deck2Win is a workspace manager for Windows 11. Save your open apps and their
window positions into named workspaces, then jump between them with a click.
Each workspace is its own virtual desktop.

## Options

- `Deck2Win.OneDir.zip` — recommended, faster startup
- `Deck2Win.OneFile.zip` — single-file build

Download from the Releases tab.
